# go-core

Вопрос: почему прямое преобразование большого int64 в int16 не проверяет диапазон?
Ответ: преобразование оставляет младшие 16 бит и отбрасывает старшие без проверки
диапазона: например, int64 со значением 32768 превращается в int16 со значением
-32768 и диапазон нужно проверить до преобразования самостоятельно.
